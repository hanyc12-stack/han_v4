# 배터리 알림이 (Android)

어르신 폰 배터리가 설정한 % 이하가 되면 자녀 여러 명에게 문자를 자동 발송합니다.

## APK 만드는 법 (컴퓨터에서 5분, 설치 프로그램 불필요)
1. github.com 로그인 → New repository 생성
2. 이 폴더의 모든 파일(.github 폴더 포함)을 업로드
3. 상단 Actions 탭 → "Build APK" → Run workflow
4. 약 3~5분 후 완료되면 맨 아래 Artifacts의 "BatteryAlert-APK" 다운로드 → 압축 해제 → app-debug.apk

## 어르신 폰에 설치
- APK를 폰으로 전송 → 열기 → "출처를 알 수 없는 앱 허용" → 설치
- 앱 실행 → 번호 입력, 기준 설정 → "알림 시작하기" → 문자 권한 허용
- "배터리 최적화 끄기" 버튼을 눌러 허용 (삼성: 설정 > 배터리 > 백그라운드 사용 제한 > 절전 예외 앱)
- "테스트 문자 보내기"로 확인
